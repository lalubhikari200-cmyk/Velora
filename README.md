# Velora

### Video & Audio Downloader for Android

Velora is a redesigned and modified open-source Android downloader based on the **Seal** project. It keeps the core downloader foundation while introducing a custom Velora interface, branding, splash experience, and UI improvements.

## ✨ Features

- Download videos and audio supported by [yt-dlp](https://github.com/yt-dlp/yt-dlp).
- Download playlists.
- Embed metadata and thumbnails into supported extracted audio files.
- Use the bundled [aria2c](https://github.com/aria2/aria2) downloader.
- Embed subtitles into downloaded videos.
- Execute custom yt-dlp commands with templates.
- Manage downloads and custom command templates.
- Material Design 3 interface with dynamic colors.
- Modern custom Velora UI and branding.
- Animated Velora splash screen.
